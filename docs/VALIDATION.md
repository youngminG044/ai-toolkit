## 별도로 확인할 것

2026-11-03 설계 설명·초보자 인계·환경 호환성 보완은 도구 테스트 77개, API 테스트 10개, 프런트 계산 테스트 3개와 TypeScript/Vite 빌드로 확인했다. 일곱 스킬 구조 검사와 build-service/record-work/explain-work/solve-task/전체 설치의 다섯 조합에서 로컬 참조·새 자료 배포·기존 README/SERVICE 보존을 확인했다. API/화면 핵심 경로의 설명 주석, SERVICE 양식의 유스케이스·라우팅·모듈 계약·읽는 지도와 조건별 설계/운영 근거를 보강했다. 그 밖의 AI/data/ML 코드와 검사 명령은 이번 변경에 포함하지 않았다.

프런트 기본 동작의 새 탭 API 링크·홈 페이지 이동·CSV/문서 네이티브 파일 선택을 제거하고 텍스트 입력·페이지 내부 탭을 유지했다. 앱 프런트 소스에서 전체화면 API·새 창·페이지 이동·네이티브 대화상자·다운로드·클립보드 호출을 정적으로 점검했다. 이는 실제 제공 IDE의 전체화면 유지·권한 창·사용자 조작을 검증한 결과가 아니다. 브라우저/OS의 전체화면 해제를 앱이 막는 기능은 구현하지 않았으며 감독 동작/로그는 변경하지 않았다.

독립 규칙 검사·조건 변화·작업 중복/실패/재시작·전체화면 호환성은 실제 업무에 적용하는 검토/기록 지침이다. 완성된 도메인 최적화·영속 작업 큐·자동 UI 안전 판정기를 새로 제공하는 것은 아니다. 실제 서비스별 검증 결과·주석 정합·사용자 이해는 해당 업무 코드와 실행/사용자 근거로 확인해야 한다. 스킬 지침만으로 모든 모델 행동이나 코드 변경을 물리적으로 차단하지 않는다.

대상 프로젝트의 스킬 발견·호출, 업무 규칙·필수 산출물·운영 조건·담당자 수용과 공유된 이해는 별도 확인이 필요하다. 문서 생성은 내용의 완성이나 이해 완료를 뜻하지 않으며, 자동저장은 미저장 에디터 버퍼를 보존하지 않는다. 명령의 정상 종료도 업무 규칙 충족을 자동으로 입증하지 않는다.

파일 관측의 자동 기록과 Codex의 판단·대안·검증 해석은 다르다. 후자는 스킬 지침으로 단계별 갱신하도록 구성했으며, 실제 업무의 코드·실행·설명 일치는 해당 작업에서 확인해야 한다.

UI의 실제 클릭·육안·좁은 화면 확인과 실제 생성 모델 연결·답변 정답률은 미검증이다. 기본 문서 답변은 BM25 검색과 원문 발췌다. 프로토타입 테스트는 인증·멀티테넌시·대규모 부하·운영 복구 검증을 포함하지 않는다.
